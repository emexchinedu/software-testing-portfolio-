# Requirements: SauceDemo
**Site:** saucedemo.com · **User:** standard_user · **Date:** 10/23/2026 · **Browser:** Chrome
## Rules the shop should follow
| # | Rule | Result |
|---|---|---|
| R1 | The shop should provide input fields for a customer to login with the correct details | Pass |
| R2 | The shop should allow customer to click the buttons | Pass |
| R3 | The shop should allow customer click on a product, click add to cart | Pass |
| R4 | The shop should allow customer to be able to remove a product from the cart | Pass |
| R5 | The shop should allow customer filter the products  | Pass |
| R6 | The shop should not give customer unclear contents to read | Fail |
| R7 | The shop should not only display the products in the cart also display the total amount of the products that was added to the cart | Fail |
| R8 | The shop should allow customer see prices of the products | Pass |

## User story
As a customer, I want to be able to click on a product, so that i can click add to cart.
### Acceptance criteria
1. The product picture must display well for customer to click
2. The product must show a price for a customer to see
3. The product must display full content for customer to understand and choose
### What if
- What if the product picture is broken ? It should have good content for customer to read.
